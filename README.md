# 社区长者智能手环告警家属确认与上门处置平台

面向社区独居老人照护场景的告警处置系统（前端单页应用）。手环上报跌倒、心率异常、长时间静止、离家未归、设备离线等告警后，平台按**告警类型、最近活动轨迹、历史误报、家属联系方式、社区值班人员**自动生成处置流程；家属端确认，社区端上门处置，全程（告警 → 确认 → 上门 → 处置 → 就医 → 回访）记录在同一事件内，结案后生成复盘报告并沉淀**照护画像**。

## 技术栈

React 18 · TypeScript · Zustand · React Router · Ant Design 5 · Vite

## 功能地图

| 模块 | 说明 |
| --- | --- |
| 告警工作台 | 待处理/升级/已结案统计，事件列表筛选，模拟手环上报；夜间跌倒无人响应升级红色横幅直达值班员处置 |
| 事件处置 | 自动生成的处置流程（含每步依据）、升级情形（家属超时/夜间跌倒升级值班员/电话无人接/低电/夜间浴室/上门无人开门/联动物业/联动120）、家属与社区双端操作、全程时间线 |
| 夜间跌倒无人响应升级 | 手环夜间触发跌倒告警，家属 5 分钟内未确认 → 页面自动升级社区值班员；升级面板集中展示老人住址、最近活动、门禁备注、钥匙托管；值班员接管 → 电话核实无果 → 派网格员上门 → 到达登记（到达时间/是否联系物业/是否需要急救）→ 上门结束后网格员补充现场报告（现场结果/老人状态/是否送医/是否复访），未补报告事件不允许关闭；家属随后响应可看到社区已采取的动作且不回退处置进度 |
| 老人档案与设备 | 姓名、住址、慢病、紧急联系人、常用活动范围、设备电量、佩戴习惯、告警阈值（可在线调整） |
| 结案复盘 | 误报原因、设备调整建议（按原因自动生成）、家属响应时长、社区处置时效、上门现场报告；事件分类：设备误报 / 照护缺口 / 真实风险 |
| 照护画像 | 结案自动沉淀：连续无人响应、频繁离线、多次上门无人在家 → 画像标签与风险等级；社区可调整巡访频次、设备维护、家属提醒方式 |
| 家属端门户 | 确认误报 / 请求电话核实 / 要求上门 / 直接拨打120，查看「社区已采取的动作」、事件进展与历史复盘 |

## 本地启动

```bash
npm install
npm run dev        # http://localhost:5173
```

生产构建与预览：

```bash
npm run build
npm run preview    # http://localhost:4173
```

端到端流程自测（告警→超时升级→夜间跌倒升级值班员→电话核实→派单门禁→到达登记→现场报告→结案门禁→家属迟响应→就医→回访→结案→画像沉淀，共 54 项断言）：

```bash
npm run test:flow  # 输出 ALL CHECKS PASSED 即通过
```

## 验证方式（本题核心流程）

以下验证均已在本地实际执行：`npm run build` 构建通过；`npm run test:flow` 54 项断言全部通过；`vite preview` 下页面正常返回 HTTP 200。

1. **登录社区端**（community/123456）→ 工作台可见 1 条进行中的「跌倒告警」（王秀兰，浴室，夜间，等级：紧急）与 1 条「设备离线」上门中事件，另有 2 条已结案事件（真实风险、设备误报）。
2. **打开跌倒事件** → 中部为自动生成的处置流程（通知家属 → 家属确认 → 电话核实 → 网格员上门 → 联动物业/120 → 回访结案，每步标注生成依据）；左侧为老人档案（慢病、联系人、轨迹、门禁、钥匙托管、上次回访）。
3. **夜间跌倒无人响应升级** → 点击顶栏「演示时间快进 +5分钟」（或等待 5 分钟）→ 事件出现「家属超时未响应」「夜间跌倒无人响应·升级值班员」升级标记，工作台出现红色升级横幅；事件页顶部展示值班员升级面板：老人住址、最近活动、门禁备注、钥匙托管一屏速览。
4. **值班员处置** → 点击「立即接管」→ 记录「电话核实：无人接」→「派单上门」按钮解锁（未电话核实前按钮禁用，直接派单也会被拦截）→ 派单后做「到达登记」：自动记录到达时间，并登记是否联系物业、是否需要急救（选"需要急救"会自动联动 120 升级）。
5. **上门结果与现场报告** → 记录上门结果（平安/无人开门/需医疗处置）；随后出现「补充上门现场报告」：填写现场结果、老人状态、是否送医、是否需要后续复访。**未补现场报告时「结案」按钮禁用**（选择送医则转入就医流程，需补记就医结果）。
6. **家属随后响应** → 退出登录，改用 family/123456 进入家属端 → 事件卡展示「您未及时确认，事件已自动升级社区值班员处置」与「社区已采取的动作」清单（电话核实、派单、到达、物业、现场报告等）；家属仍可响应，响应记录为"家属超时后响应"且不回退社区处置进度（也可在社区端事件页用「家属端操作模拟」面板操作）。
7. **回访结案** → 记录回访 → 结案并选择事件分类（设备误报需选误报原因）→ 自动生成复盘报告：误报原因、设备调整建议、家属响应时长、社区处置时效、上门现场报告。
8. **画像沉淀** → 进入「照护画像」页：该老人的误报/缺口/风险计数、家属未响应、上门无人等指标已更新，画像标签与风险等级自动重算，可调整巡访频次、设备维护、家属提醒方式。
9. **阈值调整** → 「老人档案与设备」页可修改心率/静止/围栏/归家阈值与佩戴习惯，保存后用于后续告警判定与复盘建议。
10. **模拟新告警** → 工作台「模拟手环上报」可任选老人、告警类型（跌倒/心率异常/长时间静止/离家未归/设备离线）与位置，验证不同告警生成的差异化处置流程（如低电量老人会追加「设备维护」步骤，浴室/夜间自动升级；夜间跌倒会追加「电话核实」步骤）。

## 演示说明

- 家属响应超时阈值为 **5 分钟**（夜间跌倒告警家属 5 分钟内未确认即自动升级社区值班员；顶栏「演示时间快进 +5分钟」可立即触发）。
- 数据为内存态（Zustand），刷新页面后重置为种子数据。
- 项目类型为前端单页应用，按题目约束不提供 Swagger/OpenAPI。
