# 社区长者智能手环告警家属确认与上门处置平台

面向社区独居老人照护场景的告警处置系统（前端单页应用）。手环上报跌倒、心率异常、长时间静止、离家未归、设备离线等告警后，平台按**告警类型、最近活动轨迹、历史误报、家属联系方式、社区值班人员**自动生成处置流程；家属端确认，社区端上门处置，全程（告警 → 确认 → 上门 → 处置 → 就医 → 回访）记录在同一事件内，结案后生成复盘报告并沉淀**照护画像**。

**跌倒告警无人响应升级链路**：手环在夜间触发跌倒告警后，家属 **5 分钟**内未确认，事件自动升级给社区值班员接管，处置页直接展示**老人住址、最近活动、门禁备注与钥匙托管情况**；值班员先电话核实，核实无果（无人接听）即可派网格员上门，到达时记录**到达时间、是否联系物业、是否需要急救**；家属随后响应时，家属端可查看社区已采取的全部动作且处置不回退。上门结束后网格员必须补充**现场结果、老人状态、是否送医、是否需要后续复访**，事件才允许关闭。

## 技术栈

React 18 · TypeScript · Zustand · React Router · Ant Design 5 · Vite

## 功能地图

| 模块 | 说明 |
| --- | --- |
| 告警工作台 | 待处理/升级/已结案统计，事件列表筛选，模拟手环上报（可勾选夜间场景） |
| 事件处置 | 自动生成的处置流程（含每步依据）；**夜间跌倒家属5分钟未确认自动升级社区值班员接管**（处置卡展示住址/最近活动/门禁备注/钥匙托管）；电话核实无果派单上门、到达记录（到达时间/是否联系物业/是否需要急救）、上门结束报告（现场结果/老人状态/是否送医/是否复访）作为结案门禁；家属与社区双端操作、全程时间线 |
| 老人档案与设备 | 姓名、住址、慢病、紧急联系人、常用活动范围、设备电量、佩戴习惯、告警阈值（可在线调整） |
| 结案复盘 | 上门结束报告补齐后才允许结案；误报原因、设备调整建议（按原因自动生成）、家属响应时长、社区处置时效；事件分类：设备误报 / 照护缺口 / 真实风险 |
| 照护画像 | 结案自动沉淀：连续无人响应、频繁离线、多次上门无人在家 → 画像标签与风险等级；社区可调整巡访频次、设备维护、家属提醒方式 |
| 家属端门户 | 确认误报 / 请求电话核实 / 要求上门 / 直接拨打120；社区接管后可查看**社区已采取的动作**（接管、电话核实、派单、到达与物业/急救、上门结果、120、回访），查看事件进展与历史复盘 |

## 验证方式（本题核心流程）

以下验证均已在本地实际执行：`npm run build` 构建通过；`npm run test:flow` 52 项断言全部通过；`vite preview` 下页面正常返回 HTTP 200。

1. **登录社区端**（community/123456）→ 工作台可见 1 条进行中的「跌倒告警」（王秀兰，浴室，夜间，等级：紧急）与 1 条「设备离线」上门中事件，另有 2 条已结案事件（真实风险、设备误报）。
2. **打开跌倒事件** → 中部为自动生成的处置流程（通知家属 → 家属确认 → 网格员上门 → 联动物业/120 → 回访结案，每步标注生成依据）；左侧为老人档案（慢病、联系人、轨迹、门禁、钥匙托管、上次回访）。
3. **家属 5 分钟未确认自动升级** → 点击顶栏「演示时间快进」选 5 分钟（或等待）→ 事件同时出现「家属超时未响应」与红色「社区值班员已接管」标记，状态自动转入「电话核实中」，页面顶部出现**升级处置卡**：老人住址、最近活动轨迹、门禁备注、钥匙托管情况，时间线自动追加接管记录。
4. **值班员电话核实** → 在右侧「社区处置操作」点击两次「电话无人接」→ 出现「老人电话无人接听」升级；点击「派单上门」自动匹配就近网格员刘敏（接管后未出现无人接听记录时派单按钮禁用，强制先电话核实）。
5. **记录到达** → 网格员出发后点「记录到达」，弹窗勾选「已联系物业」「现场判断需要急救」→ 到达时间、是否联系物业、是否需要急救均记录在案并触发 120 升级；呼叫 120 并记录就医结果。
6. **家属随后响应** → 退出改用 family/123456 进入家属端（或在社区端用「家属端操作模拟」）→ 页面顶部提示「您未在5分钟内确认，社区值班员已自动升级接管」，下方「社区已采取的动作」卡片逐条列出接管、电话核实、派单、到达（物业/急救）、120 等动作；家属点「要求上门查看」后，处置状态不回退、继续按社区流程推进。
7. **上门结束报告（结案门禁）** → 回到社区端，未提交上门结束报告时点「结案」会被阻止并提示原因；网格员点「补充上门结束报告」填写现场结果、老人状态（平安无碍/轻伤受惊吓/伤情较重）、是否送医、是否需要后续复访（需填复访安排）；标记需送医须先录就医结果、需复访须先完成回访，之后「结案并生成复盘」才可用。
8. **回访结案与画像** → 记录回访 → 结案选择事件分类（设备误报需选误报原因）→ 自动生成复盘报告（误报原因、设备调整建议、家属响应时长、社区处置时效）；进入「照护画像」页可见家属无人响应、真实风险等指标与标签已更新。
9. **模拟新告警** → 工作台「模拟手环上报」可任选老人、告警类型、位置，并可勾选「夜间场景」：夜间跌倒 + 家属超时即自动接管；夜间心率异常等非跌倒告警超时只升级超时、不自动接管，可对比验证。

## 演示说明

- 家属响应超时阈值为 **5 分钟**（顶栏「演示时间快进」选 5 分钟可立即触发；系统每秒自动巡检一次）。
- 自动接管仅针对**夜间跌倒告警**（22:00-06:00，或模拟上报时勾选「夜间场景」）；其他告警类型按既有升级规则处理。
- 数据为内存态（Zustand），刷新页面后重置为种子数据。
- 项目类型为前端单页应用，按题目约束不提供 Swagger/OpenAPI。
